This site runs no analytics and sets no tracking cookies. The pages are served by GitHub Pages, and the mailing list interface by a server run for GPOTS; both keep ordinary web server logs.

## The mailing list

If you subscribe, we store the email address you give us and, if you enter one, your name. That is everything we hold about you.

The address is used only to send announcements about the conference. It is not sold, and it is not shared with anyone outside the people organizing GPOTS.

Subscriptions are confirmed. After you sign up, that address is sent a message asking you to confirm, and nothing is added to the list unless you answer it. An address that never confirms is discarded.

To leave, send an empty message to [announce-leave@gpots.org](mailto:announce-leave@gpots.org), or use the unsubscribe link at the foot of any message from the list. Removal is immediate and the address is deleted.

Announcements are delivered through Amazon Web Services, which handles the messages in transit.
